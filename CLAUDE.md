# Arbeitsregeln für dieses Repository

- **Jede Änderung sofort hochladen:** Nach jeder abgeschlossenen Änderung `npm test` ausführen, committen und auf `main`
  pushen (Wunsch des Besitzers). Nicht auf eine Rückfrage warten.
- Vor jedem Commit `npm test` (Bibliothekstest + 3D-Kollisionstest). Alle Tests müssen grün sein; Tests nie abschwächen.
- `dist/` ist generiert und nicht im Repo (`npm run build`).
- README bei neuen Funktionen oder Geräten mitpflegen.
- Neue Geräte: Genauigkeit in `source` angeben (vermessen / abgeleitet / Datenblatt / Schätzung).
- UI-Texte auf Deutsch, Code-Kommentare Englisch.
